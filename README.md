## 📌 What It Does
 
A production-ready Learning Management System that lets instructors create and manage courses, track student progress, and handle enrollments — with separate dashboards for admins, instructors, and students.
 
---
 
## ✨ Key Features
 
- **Role-based dashboards** — Separate views for Admin, Instructor, and Student
- **Course management** — Create, edit, and publish courses with video/resource support
- **Student enrollment & progress tracking** — Real-time progress indicators per course
- **Secure authentication** — JWT-based auth with protected routes per role
- **Responsive UI** — Works seamlessly across desktop and mobile
 
---
 
## 🛠️ Tech Stack
 
React · Node.js · Express.js · MongoDB · Tailwind CSS · JWT Auth

## 🚀 Getting Started
 
```bash
git clone https://github.com/Ali-Raza-12/Learning-Management-System.git
cd Learning-Management-System
 
# Frontend
npm install
npm start
 
# Backend
cd server
npm install
npm run dev
```
 
Add `MONGODB_URI` and `JWT_SECRET` to your `.env`.
